# WarmeHands Logistics Inc. – Business Analysis Dashboard

## Project Overview
This project focuses on analyzing business data for WarmeHands Logistics Inc. using Microsoft Power BI. The objective is to transform raw data into meaningful insights through interactive data visualizations and reports.

## Tools & Technologies
- Microsoft Power BI
- Data Cleaning and Transformation
- Data Visualization
- Business Intelligence

## Project Objectives
- Analyze business performance.
- Identify key trends and patterns.
- Present important business insights.
- Support data-driven decision-making.

## Dashboard
The Power BI dashboard is available in the repository as `project.pbix`.

## Key Learnings
- Working with business data.
- Creating interactive Power BI dashboards.
- Presenting data insights through visualizations.
